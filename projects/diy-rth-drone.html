DIY Return-to-Home Drone

Custom-built quadcopter with an STM32 BluePill flight controller implementing GPS-based Return-to-Home (RTH). Features a PID control loop for stable flight, IMU sensor fusion (accelerometer + gyroscope), and autonomous waypoint navigation — all running on a bare-metal ARM Cortex-M3 at 72 MHz.

Engineering
Key Design Decisions
🎮

STM32 BluePill as FC

The STM32F103C8T6 (BluePill) provides 72 MHz ARM Cortex-M3, multiple timers for PWM generation, hardware I2C/UART for sensors, and DMA — all at under $2. Enough compute for a 1 kHz PID loop with GPS processing.

🧭

GPS RTH Algorithm

Stores home coordinates on arm. On signal loss or RTH trigger, calculates bearing and distance to home using Haversine formula, then commands heading and altitude hold until within landing radius.

🔄

Complementary Filter Fusion

Fuses accelerometer and gyroscope data with a complementary filter — gyro for fast attitude changes, accelerometer for long-term drift correction. Simpler than Kalman with acceptable performance for hobby flight.

⚙️

Cascaded PID Loops

Separate PID controllers for roll, pitch, yaw rate, and altitude. Rate PIDs run at 1 kHz using gyro data; angle PIDs at 250 Hz using fused attitude. Manual tuning via serial console.
